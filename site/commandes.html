Commandes

Le moteur en ligne de commande sert surtout à l’agent et au bot iterion. Voici les quelques commandes utiles à la main, à lancer avec npx ultra11y <commande>. La liste complète des options : npx ultra11y --help.

Les commandes d’ultra11y qu’une personne peut lancer elle-même
CommandeRôle
audit <chemins> --standard rgaa --out audits --jsonPasse le moteur statique sur le code et écrit audits/audit-latest.json.
scan <url> --merge audits/audit-latest.jsonOuvre une page dans un navigateur, la mesure et fusionne le résultat. --sample parcourt l’échantillon déclaré.
report --in audits/audit-latest.json --standard rgaa --htmlÉcrit le rapport RGAA daté, en Markdown et en HTML imprimable.
pages --in audits/audit-latest.json --format report --split pageÉcrit un dossier par page, avec sa capture d’écran.
check --report <rapport.md>Contrôle l’intégrité d’un rapport : aucun critère inventé, aucun NA sans justification.
tickets --in audits/audit-latest.json --dry-runPrépare les tickets GitHub, GitLab ou Jira. Sans --dry-run, les crée.
criteria --standard rgaa 8.3Affiche le texte officiel d’un critère, ses tests et les définitions du glossaire.
install --all · statusBranche la relecture automatique dans les agents détectés, et dit ce qui est réellement actif.

--standard rgaa peut être fixé une fois pour toutes dans .ultra11yrc.json : { "standard": "rgaa" }. Un audit lancé à la main n’est qu’un premier aperçu : sans arbitrage ni contre-vérification, la plupart des critères restent « à évaluer ». L’audit complet passe par l’agent (voir Audit).

Documentation détaillée

Les fichiers de référence de la skill, sur GitHub (en anglais) :

  • full-audit.md : l’audit complet, le même sur Claude Code, Codex et OpenCode
  • judgment.md : les fiches d’arbitrage et de contre-vérification
  • verify.md : les garde-fous check et verify
  • methodology.md : statuts, taux, gravités, format du rapport
  • pages.md : copies de pages et grille page par page
  • e2e.md : Playwright et Cypress
  • ci.md : la CI avec le bot rgaa-audit d’iterion
  • harnesses.md : les différences entre Claude Code, Codex et OpenCode
  • rgaa-automation.md : la matrice des 258 tests RGAA (générée)
  • packs.md : ajouter le référentiel d’un autre pays
