Commandes : la référence condensée

Toutes les commandes s’utilisent avec npx ultra11y <commande>, sans installation. La liste complète des options est dans npx ultra11y --help.

Deux options valent pour presque toutes les commandes : --standard rgaa fait parler toute la sortie en critères RGAA, et --lang fr choisit la langue des messages. .ultra11yrc.json peut fixer ces valeurs par défaut pour le dépôt.

Auditer

audit <fichiers…>
Lance le moteur statique. --graph suit les imports entre fichiers, --out audits --json enregistre audits/audit-latest.json. audit - < page.html lit l’entrée standard.
audit --staged · --changed · --since <ref>
N’audite que les fichiers indexés, le diff de travail ou la branche depuis une référence git. --fail-on blocking|major|minor fixe le seuil d’échec.
scan <url> --runtime local --merge audits/audit-latest.json
Ouvre la page dans un navigateur, lance axe-core et les sondes, fusionne le résultat. --sitemap, --crawl ou --sample pour plusieurs pages ; --storage-state pour une page derrière une connexion.
pages discover --crawl <url> --write · sample check
Construit l’échantillon de pages dans .ultra11yrc.json, puis vérifie qu’il couvre les types de pages attendus par le RGAA.
render --setup · render --e2e
Capture le HTML produit par vos composants pendant les tests, ou écrit les fixtures Playwright et Cypress.

Juger et vérifier

verify --manual --in audits/audit-latest.json --out audits
Écrit les fiches d’arbitrage, une par critère non tranché, pour l’agent IA.
verify --apply audits/ADJUDICATE.todo.json --in audits/audit-latest.json --out audits
Réintègre les verdicts, en refusant tout verdict non prouvé.
verify --report <rapport.md> --in audits/audit-latest.json
Contre-vérifie les non-conformités et les conformités déjà prononcées.
check --report <rapport.md> · check --in <audit.json> --require-decided
Contrôle l’intégrité d’un rapport, ou échoue tant qu’un critère reste « à évaluer » sans raison déclarée.
judge --in audits/audit-latest.json
Fait juger les critères par un modèle quand aucun agent n’est là (CI, extension). Mêmes fiches, mêmes garde-fous.
criteria --standard rgaa 8.3
Affiche le texte officiel d’un critère, ses tests numérotés et les définitions du glossaire.

Produire les livrables

report --in audits/audit-latest.json --standard rgaa --out audits
Le rapport daté et son annexe technique. --html pour une version imprimable, --format sarif|github pour la CI.
pages --in audits/audit-latest.json --standard rgaa
La grille critère par page. --format report --split page pour un dossier par page.
prd --in audits/audit-latest.json
Le backlog de corrections.
tickets --in audits/audit-latest.json --dry-run
Prépare les tickets GitHub, GitLab ou Jira. Sans --dry-run, les crée. Relancer ne crée pas de doublon.

Corriger et brancher

fix <fichiers…> --write --iterate
Applique les corrections sûres. Sans --write, montre seulement ce qui changerait.
init --hook · init --ci · init --baseline
Installe un hook git avant commit, un workflow de CI, ou une référence pour ne bloquer que les nouvelles non-conformités.
install --all · status
Branche la relecture automatique dans les agents détectés, et dit ce qui est réellement actif.
dev · dev --next
Panneau de non-conformités en direct pendant le développement.
mcp
Lance le serveur MCP. --allow-write ajoute les outils qui modifient le projet (fix, init).
pack check <pack.json>
Valide un paquet de référentiel (un autre pays, par exemple) avant de l’utiliser.

Documentation détaillée

Les fichiers de référence de la skill, sur GitHub (en anglais) :

  • audit.md : la boucle d’audit et l’échantillon de pages
  • runbook.md : la recette fiable pour un audit complet
  • adjudication.md : comment trancher chaque critère de jugement
  • judgment.md : les fiches d’arbitrage et de contre-vérification
  • verify.md : les garde-fous check et verify
  • methodology.md : statuts, taux, gravités, format du rapport
  • dynamic.md : le scan navigateur et ses sondes
  • pages.md : copies de pages et grille page par page
  • ci.md : la GitHub Action, SARIF, annotations
  • e2e.md : Playwright et Cypress
  • mcp.md : le serveur MCP
  • rgaa-automation.md : la matrice des 258 tests RGAA (générée)
  • act.md : le score sur le corpus W3C ACT, règle par règle (généré)
  • standards.md et packs.md : référentiels nationaux et paquets
  • review-a11y/SKILL.md : la skill de revue de code
