ultra11y

This extension does not audit anything by itself: it collects the page and hands it to ultra11y dev running on your machine. The page's DOM goes to that local process and nowhere else — the extension can only reach loopback.

The port ultra11y dev is listening on. Default 4111.

Set on the server with ultra11y dev --standard rgaa; shown here for reference.

Only used by “Adjudicate with AI”, which rules on the criteria no static engine can decide. It is kept in this browser's local extension storage, sent to your local server per request, and never written to disk by it. Leave it empty to let the server use its own ANTHROPIC_API_KEY instead. Everything else in ultra11y works with no key at all.
